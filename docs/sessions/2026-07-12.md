# Session (part 3): exelban/stats integration + richer detail cards + Tahoe reorder fix

## Goal
Mine exelban/stats (40k-star MIT menu-bar monitor) for integrable data sources, enrich
the detail cards, and fix the user-reported "Settings reorder not reflected in the strip".

## Progress
- **Per-core CPU/GPU temperatures via SMC** — new `Sampling/SMCTemperatureTable.swift`:
  the M1–M5 SMC temp-key→role map ported from exelban/stats (MIT, attributed). A live
  probe first proved 17/25 M4-gen keys answer on this M4 Pro (type `flt`, our decoder).
  `TemperatureReader` now opens a read-only SMC handle beside its IOHID client, probes
  the key union once at init (no chip detection — absent keys just don't answer), and
  merges per role: SMC named cores win, IOHID fills gaps, redundant "SoC" row suppressed.
  Card went from `SoC/SSD/Battery` to `CPU 57° / GPU 51° / SSD 40° / Battery 33°`.
- **Power card whole-machine rows** — `PowerSampler` reads SMC `PSTR`/`PDTR` each tick:
  new "System" (whole-Mac draw, e.g. 10.4 W vs ~1.2 W SoC idle) + "DC In" (charger input)
  rows under the IOReport SoC split; key presence fixed at start so the card never flaps.
- **Richer detail rows** (user-picked from a review of Stats' popups):
  Memory App/Wired/Compressed (same vm_statistics64 read, App = internal − purgeable,
  saturating); Battery Health/Cycles/Temp (AppleSmartBattery registry —
  NominalChargeCapacity÷DesignCapacity, Temperature is centi-°C, keys probe-verified);
  Network Interface + Local IP ("Wi-Fi (en0)", getifaddrs + SystemConfiguration names,
  deliberately NO public IP — zero-network-requests property kept); CPU & GPU cards each
  gained a Temp row fed by the temps sample's per-role data.
- **Reorder bug fixed** — persisted `statOrder` proved no reorder ever committed since
  June 15; display path provably re-derives per summon; the row was 100% `Toggle`
  (checkbox+label one control) so macOS 26's List gives the control the mouse-down and
  `.onMove`'s drag never starts. Fix: checkbox and label are separate views — label is
  inert and draggable; checkbox alone toggles. Trade-off: clicking row text drags, no
  longer toggles.
- **Verification:** clean builds 0 warnings; standalone `swiftc` harnesses compiled the
  *production* sampler files and printed real rows (temps merge, battery health 97%/88
  cycles/31°C, Wi-Fi (en0) + local IP). All user-verified on screen ("looks good").
